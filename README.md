# AI Resume Analyzer

An AI-powered resume analysis web application that analyzes PDF resumes and provides useful insights to help candidates improve their resumes and understand suitable job roles.

---

## 🚀 Features

- Upload PDF resume
- Extract text from PDF resume
- Calculate resume score out of 100
- Detect technical skills
- Calculate resume word count
- Match resume with suitable job roles
- Match resume with a specific job description
- Identify matched and missing skills
- Generate resume improvement suggestions
- Clean and responsive web interface
- FastAPI REST API backend

---
