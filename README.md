# 🤖 AI Resume Analyzer

An AI-powered web application that analyzes PDF resumes and provides useful insights such as resume score, technical skills, job-role matching, and resume improvement suggestions.

The application provides a simple and user-friendly interface where users can upload their resume and instantly receive an analysis.

## ✨ Features

- 📄 Upload PDF resume
- 🔍 Extract text from PDF resumes
- 📊 Calculate resume score
- 🛠️ Detect technical skills
- 💼 Match resume with different job roles
- 🎯 Match resume with a specific job description
- 💡 Provide resume improvement suggestions
- 📝 Display resume word count
- 📱 Responsive and user-friendly interface
- 🌐 Deployed online using Render

---

## 🖥️ Application Preview

The application provides a clean dashboard where users can:

1. Upload their PDF resume
2. Analyze the resume
3. View the resume score
4. View detected technical skills
5. Check suitable job roles
6. Enter a job description
7. Compare the resume with the job description
8. View matching results and suggestions
